<# Lexie Reward Tracker Roadmap

## Vision

Create a fun mobile-first reward app that motivates positive habits and converts achievements into YouTube time.

The experience should feel like a game rather than a chore chart.

---

# Version 1 ✅ Complete

## Goals

Create a working reward tracker.

## Delivered

- GitHub repository created
- GitHub Pages deployment working
- Single-file application
- Local storage persistence
- Points system
- YouTube minute conversion
- K-pop-inspired theme
- Mobile-friendly interface

## Lessons Learned

- GitHub Pages is a suitable hosting platform
- Single file deployment keeps updates simple
- LocalStorage provides sufficient persistence for first release

---

# Version 2 🚧 Current Development

## Objectives

Turn the tracker into a proper game.

## Features

### Daily Task Locking

- Tasks can only be completed once per day
- Daily reset at midnight

### YouTube Bank

- Visible minute balance
- Spend 15 minutes
- Spend 30 minutes
- Spend 60 minutes
- Never allow negative balance

### Parent Controls

- Parent PIN
- Add/remove points
- Add/remove minutes

### Improved Dashboard

- Better progress indicators
- More visual feedback
- Celebration animations

## Success Criteria

Lexie can use the app largely independently.
